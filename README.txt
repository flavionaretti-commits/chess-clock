CHESS CLOCK! — PWA

File pronti per GitHub Pages.

Caricare nella RADICE della repository:
- index.html
- manifest.webmanifest
- service-worker.js
- cartella assets (con sottocartelle audio e icons)

Poi in GitHub:
Settings > Pages > Build and deployment > Deploy from a branch
Branch: main / (root)

La PWA ha un ID dedicato (./chess-clock-pwa) per non confondersi con altre app installate.
Dopo il primo caricamento funziona anche offline.
